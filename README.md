# 루틴런 중고등 · 깃허브 + 앱스크립트 버전 설치 안내

화면은 **깃허브 페이지**(빠르게 열림), 기록·로그인·오류는 **구글 시트 + 앱스크립트**가 맡아요.

```
학생 폰 ──(화면)── 깃허브 페이지  index.html / admin.html
   │
   └──(기록·로그인)── 앱스크립트 웹 앱 ── 구글 시트 [계정] [기록] [승인] [오류]
```

| 폴더 | 어디에 넣나요 |
|---|---|
| `site/` | 깃허브 저장소에 올리는 파일 4개 (`index.html`, `admin.html`, `config.js`, `version.json`) |
| `apps-script/` | 구글 시트의 앱스크립트에 붙여 넣는 코드 (`Code.gs`, `appsscript.json`) |

---

## 1단계. 구글 시트와 앱스크립트 (약 10분)

1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `루틴런 서버`로 정해요.
2. 메뉴 **확장 프로그램 > Apps Script**를 눌러요.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S)해요.
4. 왼쪽 톱니바퀴 **프로젝트 설정**에서 시간대를 **(GMT+09:00) 서울**로 바꿔요.
   (또는 "appsscript.json 매니페스트 파일 표시"를 켜고 `apps-script/appsscript.json` 내용을 붙여 넣어도 돼요.)
5. 시트 탭으로 돌아가 **새로 고침**하면 위쪽에 **루틴런** 메뉴가 생겨요.
6. **루틴런 > 1. 처음 설정**을 눌러요.
   - 처음 한 번은 권한 확인 창이 떠요. 내 구글 계정 선택 → "고급" → "루틴런 서버(으)로 이동" → 허용. (내가 만든 스크립트라 안전해요.)
   - 관리자 아이디(예: `teacher`)와 비밀번호(8자 이상)를 넣으면 [계정] [기록] [승인] [오류] 탭이 생겨요.

## 2단계. 웹 앱으로 배포 (약 3분)

1. 앱스크립트 화면 오른쪽 위 **배포 > 새 배포**.
2. 톱니바퀴에서 유형 **웹 앱** 선택.
3. **다음 사용자 인증 정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**.
4. **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둬요.

> "모든 사용자"여도 아이디·비밀번호(또는 학부모 코드) 없이는 아무 기록도 볼 수 없어요.

## 3단계. 깃허브 페이지 (약 5분)

1. github.com 에서 **New repository** → 이름 예: `routinerun` → **Public** → Create.
2. **Add file > Upload files**로 `site/` 안의 파일 4개를 끌어다 놓고 **Commit changes**.
3. 저장소에서 `config.js`를 열고 연필(✏️)을 눌러 `API_URL: ''` 따옴표 안에 2단계의 웹 앱 URL을 붙여 넣고 Commit.
4. **Settings > Pages**에서 Branch를 **main / (root)**로 두고 Save.
5. 1~2분 뒤 `https://내깃허브아이디.github.io/routinerun/` 이 학생 주소, 뒤에 `admin.html`을 붙인 주소가 선생님 주소예요.

> Public 저장소라 코드는 누구나 볼 수 있지만, 학생 기록과 비밀번호는 시트에만 있고 저장소에는 없어요.

## 4단계. 학생 계정 나눠 주기

1. `…/admin.html`에 관리자 아이디로 로그인.
2. **계정 만들기**에서 한 명씩, 또는 `아이디, 이름, 메모`를 여러 줄 붙여 넣어 한 번에 만들어요. 비밀번호는 비워 두면 8자리로 자동 생성돼요.
3. 나온 **안내문 복사** 버튼으로 학생에게 카톡으로 보내요 (주소 + 아이디 + 비밀번호).
4. 학부모 링크는 **학생 계정 > 학부모 링크**에서 복사해요. 로그인 없이 그 학생 리포트만 열려요.

---

## 매일 쓰는 법 (선생님)

- **오늘** 탭: 외우기 인증 승인(인증 시 외우기 3점→5점), 학생별 오늘·이번 주·이번 달 점수, 오늘의 몰입 칸, 마스터의 가호. 30초마다 자동 새로 고침.
- **학생 계정** 탭: 비밀번호 새로 발급, 계정 멈추기(그 학생은 바로 로그아웃), 학부모 링크, 입장 안내.
- **오류 기록** 탭: 학생 폰에서 난 오류와 학생이 [나 > 오류·불편한 점 알리기]로 보낸 신고가 실시간으로 쌓여요. 구글 시트 [오류] 탭에도 같은 내용이 있어요.

## 고치거나 업데이트할 때

- **화면(학생·관리자)**: 깃허브에서 `index.html`이나 `admin.html`을 새 파일로 바꾸고, `version.json`의 version 값도 같이 바꿔요. 열려 있는 학생 화면에 "새 버전이 나왔어요 · 새로 고침" 버튼이 떠요. 깃허브 페이지는 반영까지 1~10분 걸릴 수 있어요.
- **서버(Code.gs)**: 앱스크립트에서 코드를 바꾸고 저장한 뒤 **배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포**. 이렇게 해야 웹 앱 URL이 그대로 유지돼요. ("새 배포"를 누르면 URL이 바뀌니 주의.)

## 속도에 대해

- 앱스크립트는 요청 한 번에 1~3초 걸려요. 그래서 학생 화면은 **공격·체크가 폰에서 바로 반영**되고, 저장은 1.2초 뒤 뒤에서 한 번에 보내요.
- 다시 열 때도 폰에 보관된 기록으로 **바로 화면이 뜨고**, 서버 기록은 뒤에서 맞춰요.
- 인터넷이 끊기면 폰에 보관했다가, 다시 연결되면 자동으로 올려요. 화면 아래에 "저장 대기 중"이 보이면 아직 안 올라간 상태예요.

## 보안 메모

- 비밀번호는 원문 없이 `솔트 + SHA-256 500번 반복` 해시로만 [계정] 탭에 저장돼요. 선생님도 원래 비밀번호를 볼 수 없고, 잊으면 새로 발급해요.
- 로그인 토큰은 60일 유효. 비밀번호를 바꾸거나 새로 발급하거나 계정을 멈추면 예전 기기는 바로 로그아웃돼요.
- 같은 아이디로 비밀번호를 8번 틀리면 10분 동안 잠겨요.
- 학부모 링크가 새어 나갔다면 [계정] 탭에서 그 학생의 학부모코드 칸을 다른 10자리 영문·숫자로 바꾸면 예전 링크는 막혀요.
- [계정] [기록] 시트는 직접 고치지 않는 게 좋아요. 계정 관리는 관리자 화면에서 해 주세요.
